# Python TOML formatters

This repository contains two comment-preserving TOML formatters:

- `pyproject-fmt` formats `pyproject.toml`. See its [PyPI package](https://pypi.org/project/pyproject-fmt),
  [guide](https://pyproject-fmt.readthedocs.io), and
  [release history](https://github.com/tox-dev/toml-fmt/releases?q=pyproject-fmt).
- `tox-toml-fmt` formats `tox.toml`. See its [PyPI package](https://pypi.org/project/tox-toml-fmt),
  [guide](https://tox-toml-fmt.readthedocs.io), and
  [release history](https://github.com/tox-dev/toml-fmt/releases?q=tox-toml-fmt).

Both packages provide a command-line tool, Python API, and pre-commit hook. See [CONTRIBUTING.md](CONTRIBUTING.md) for
the workspace layout and development commands.
